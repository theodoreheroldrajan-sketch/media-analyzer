# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The full text is available at the link above. All participants in this project's issue trackers, discussions, pull requests, and other spaces are expected to follow it.

## Enforcement

Report unacceptable behaviour via GitHub's Private Vulnerability Reporting on this repo (Security tab > Report a vulnerability). This is a private channel; the project maintainer will respond directly.
